Evidence and boundaries

The planner checks a supplied model. It does not execute GPU kernels, establish production p95, attest a supplier's quote, validate an LLM's output quality, or convert cheaper batches into additional physical GPU capacity.

Transfers use one serialized shared fabric. Resource slots are exclusive. Data is assumed to reside in a durable staging store; source write/upload and in-resource offload belong in the supplied stage duration. Storage retention, outages, retries, queueing and operator labor require explicit additional profiles or costs; this v0.1 does not model them automatically.

A measured profile label means a trace was supplied; the digest establishes content integrity, not independent authenticity. Use the CPU benchmark verifier for the included local control path.
